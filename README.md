# Movie Recommender System

This project implements a **Movie Recommender System** that utilizes **cosine similarity** to suggest movies based on user preferences. By analyzing movie metadata such as **genres, cast, crew, and plot summaries**, the system identifies and recommends movies that are most similar to a given input movie.

### Dataset
The dataset used for this project consists of two main datasets: **Movies** and **Credits** from **TMDB Movie Metadata**. These datasets provide essential movie-related metadata required to power the recommender system.

You can find the dataset for this project here: [**TMDB Movie Metadata**](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata).
